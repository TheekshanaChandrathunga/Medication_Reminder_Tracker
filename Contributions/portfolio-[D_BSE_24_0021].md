## Project Area

My work covered two main areas:

1. The complete UI/UX design of the application in Figma for both patients and caregivers.
2. The patient-side frontend implementation using Flutter.

## My Role

I worked as a **UI/UX designer and frontend developer** for the Medication Reminder & Tracker project. My main responsibility was designing the complete application UI in Figma and developing the patient-side frontend.

## UI/UX Design Contribution

- Designed the complete application user interface and user flows in Figma for both patients and caregivers.
- Created the Figma designs for the patient and caregiver dashboards.
- Designed screens for medication management, medication details, history, reports, profiles, and settings.
- Planned the main user flows for registration, login, medication tracking, and profile management.
- Used consistent colors, typography, spacing, cards, buttons, and navigation elements across the designs.
- Focused on accessibility by using readable text, clear labels, simple layouts, and touch-friendly controls.

## Frontend Development Contribution

- Developed the patient-side frontend using Flutter.
- Implemented and styled the splash, registration, and login screens.
- Developed the patient home dashboard and medication-related screens.
- Implemented the medication list, add medication, medication details, and history screens.
- Developed the reports, profile, and settings screens.
- Connected the screens with the application's navigation and authentication flow.
- Added user-friendly form validation, loading indicators, password visibility controls, and error messages.
- Adjusted layouts so that the screens could work more effectively on different screen sizes.

## Development Process

I first planned the screen structure and user journeys in Figma. After creating the designs, I converted the patient screens into Flutter widgets and connected them to the existing application structure. I checked the navigation between screens and updated the layouts to keep the design consistent with the Figma work.

## Challenges I Faced

- Converting the Figma designs into responsive Flutter layouts.
- Keeping both patient and caregiver interfaces simple, clear, and accessible.
- Maintaining a consistent design across all screens and user roles.
- Managing form validation, loading states, error handling, and navigation.
- Matching the Flutter implementation with the original Figma designs while working with the existing project structure.
- Designing screens that show medication information clearly without making the interface difficult to use.
- Making changes to the frontend while keeping the existing project navigation and functionality working.

## Skills and Experience Gained

- Gained practical experience developing Flutter interfaces.
- Improved my understanding of responsive layouts and reusable UI components.
- Learned how to connect frontend screens with navigation, authentication, and user interactions.
- Developed experience working with an existing project structure and coordinating design and implementation.

## Outcome

My contribution provided the complete Figma UI design for both patients and caregivers, along with the patient-facing Flutter frontend.
