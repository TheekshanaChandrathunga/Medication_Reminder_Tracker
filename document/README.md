# Medication Reminder & Tracker App — UI Design

This folder contains the UI wireframes and Figma UI designs for the **Medication Reminder & Tracker App**.

The UI design is based on the requirements defined in the Software Requirements Specification (SRS). The application is designed to help patients and caregivers manage medication schedules, receive reminders, and track medication adherence.

## UI Design

### Figma Design

The complete UI design is available in Figma:

**Figma Link:**
https://www.figma.com/design/RY6Qv4Ga8XAQkWthA2u47J/Untitled?node-id=0-1&t=2mqgwaGCk4ltFoel-1

## Design Considerations

The UI is designed with simplicity and accessibility in mind, particularly for elderly users. The design follows the requirements specified in the SRS, including:

* Clear and simple navigation
* Large and readable text
* High color contrast
* Large touch-friendly buttons
* Easy access to medication schedules
* Clear indication of Taken, Missed, and Snoozed medication
* Simple medication management
* Accessible medication history and reports

## Purpose of the Design

The wireframes were created to establish the basic screen structure and user flow. The Figma design provides the more detailed visual representation of the application's user interface.
